Color Palette:

Deep Brand Teal (#006D60): Main brand color for headers, dominant backgrounds, and primary navigation. Establishes security and SaaS reliability.

Accent Coral (#E07B69): Extracted from the dynamic shopping cart icon. Perfect for high-conversion Call-to-Actions (CTAs), checkout prompts, and interactive highlights.

Pure White (#FFFFFF): Used for main card surfaces and high-contrast text over dark teal blocks.

Soft Surface Gray (#F4F6F6) & Light Beige (#EEEEEE): App background options to ensure a modern, clean grid view for products and metrics.

2. Typography Strategy

Arabic Fonts: Recommended modern rounded geometric fonts like Cairo or Tajawal to perfectly match the welcoming, curved geometry of the logo text ("زيرو كشك").

Latin Fonts: Friendly, modern sans-serifs with rounded terminals like Fredoka or Quicksand to complement the interface seamlessly.

3. UI Components

Border Radius: Substantial rounding (8px to 16px) on cards, buttons, and input fields to maintain visual alignment with the logo design elements.

Subtle Shadows: Light, desaturated teal shadows (rgba(0, 109, 96, 0.05)) to keep dashboard layouts sharp and professional.
